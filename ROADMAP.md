# Roadmap

0.1: bounded Query IR, schema builder, read-only SELECT subset, inner joins, filters, grouping, ordering, limits, five parameter styles, allowlist and tenant policy, CLI, CMake/Make, tests, amalgamation.

Next: typed semantic layer, canonical serializer, source offsets and structured diagnostics, deterministic fast paths, inference callback/prompt builder, relevance projection, fingerprints/cache callbacks, CTE/window/set-operation support, complete dialect conformance, fuzz harnesses, bindings, SBOM/provenance, and CI matrix.

No release should be called production-ready until those gates have real passing evidence.
