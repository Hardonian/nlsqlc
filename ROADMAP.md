# Roadmap

0.1.1 hardening completed: deny-column enforcement, FK join validation, typed parameters, canonical IR output, native CLI schema/policy formats, and `validate-ir`.

Next: question fast paths, inference callback/prompt builder, semantic metrics, relevance projection, fingerprints/cache callbacks, CTE/window/set-operation support, full dialect fixtures, fuzz harnesses, bindings, SBOM/provenance, and complete API documentation.

No release should be called production-ready until those gates have real passing evidence.
