# Roadmap

0.1.2 hardening completed: deny-column enforcement, FK join validation, typed parameters, canonical IR output, native CLI schema/policy formats, `validate-ir`, static CLI packaging, and deterministic question fast paths (`count`, `list`, `sum`, `average`).

Next production features: inference callback/prompt builder, semantic metrics, relevance projection, fingerprints/cache callbacks, CTE/window/set-operation support, full dialect fixtures, fuzz harnesses, bindings, signed provenance, stable schema/policy ABI, and complete API documentation.

No release should be called enterprise 1.0-ready until those gates have real passing evidence.
